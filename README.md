# Тренажёр к вступительному экзамену в магистратуру по экономической теории

Одностраничное веб-приложение без зависимостей: открывается двойным щелчком по
`trenazher.html`, работает офлайн, ничего никуда не отправляет. Прогресс
хранится в localStorage браузера.

## Что внутри

**1834 вопроса** из банка вступительного испытания, каждый с трёхблочным
разбором. Ключи взяты из официального ключа Moodle и не менялись: там, где
формулировка спорна, сомнение вынесено отдельной фразой в конце разбора.

## Разбор после ответа

У каждого вопроса три блока, а не один «правильный ответ»:

- **Почему так** — механика нормы или понятия на 3-5 предложений; у расчётных
  вопросов вычисление расписано по шагам с числами
- **Почему остальные не подходят** — по каждому неверному варианту отдельно, на
  какой подмене понятий он построен
- **Как запомнить** — короткая мнемоника или логическая зацепка

## Режимы

1. **Тренировка по темам** — все вопросы одной темы подряд, разбор сразу после
   ответа
2. **Вариант экзамена** — 40 вопросов поровну из всех 16 тем, проверка в конце,
   результат по темам
3. **Работа над ошибками** — накопленные промахи
4. **Весь банк вперемешку**

Тренажёр помнит готовность по каждой теме, список ошибок и незаконченную
попытку: вышли посреди варианта — на главной появится карточка «продолжить».

## Структура репозитория

```
trenazher.html            собранный файл — открывать этот
index.html                редирект на тренажёр
trainer/
  собрать.py              склейка trenazher.html из частей build/
  собрать-банк.py         генерация банка из базы вопросов и разборов
  проверить.py            структурная проверка банка перед сборкой
  build/
    01-стили.html
    02-разметка.html
    банк.js               данные: window.ТЕМЫ и window.БАНК
    03-логика-данные.html  хранилище прогресса, проверка ответов
    04-логика-главная.html режимы, выбор темы, карта готовности
    05-логика-вопрос.html  отрисовка вопроса, ввод ответа, таймер
    06-логика-разбор.html  разбор и экран результата
    СПЕЦИФИКАЦИЯ.md        формат данных банка
```

`trenazher.html` **генерируется** — правки вносятся в `build/`, затем:

```bash
python3 trainer/собрать-банк.py   # если менялись база или разборы
python3 trainer/проверить.py      # структурная проверка банка
python3 trainer/собрать.py        # пересборка trenazher.html
```

Исходники банка (страницы Moodle, разбор по темам, тексты разборов) лежат в
отдельном проекте `Экзамен-база`; сюда попадает только собранный `банк.js`.

## Известные дефекты исходных данных

- **71764, 72206, 72207** — в исходной странице Moodle два варианта ответа
  слиты в одну строку; разбор написан по фактически сохранённым вариантам.
- **72325** — два варианта ответа совпадают дословно.
- Несколько заданий на соответствие содержат вариант с текстом `-`: так он
  заведён в самом Moodle, и ключ ссылается именно на него.

## Статус

Учебный проект для личной подготовки, не является официальным материалом вуза.
